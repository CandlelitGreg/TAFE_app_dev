Event Horizon Connect Mobile Application
Written and Created by Greg Wilkinson

This application intends to connect residents and staff with the relevant information for the events they are interested in, including the functionality to register to these events, and download their information to be used offline.
The current iteration includes a fetch of remote data to display a list of events that can be viewed and 'registered' to.
No real register functionality has been implemented, but the basic search, navigation, and filtering system is in place.

At this stage, Event Horizon Connect Mobile Application requires React Native and Expo to run.

The project is still in early development with its initial sprint complete.
The next sprint will include storing the event data in a state that is easier to manipulate to allow for event adding, updating/editing, and deleting functionality to be implemented.
This will also allow for the addition of user profiles/accounts to implement stored registrations and user data for each event.
